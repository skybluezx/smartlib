# 论文与代表作入库

```sh
publication-preview --file /绝对路径/论文.csv
publication-import --file /绝对路径/论文.csv --source-label '2026年本馆论文采集' --apply
publication-list --q '题名或DOI'
publication-detail --id <采集记录UUID>
```

支持 UTF-8 CSV、XLSX 首个工作表，20 MB、5000行。预检直接复用项目 `publications/intake.py`，不另造字段规范。题名必需；DOI、年份缺失可以进入人工核验队列。作者用分号分隔；声明成果归属人但没有作者列表时不能自动确认归属。额外字段保留为来源元数据。

脚本会额外阻断同义字段重复列、表头外数据、重复 DOI/完全重复行、公式单元格和非整数年份，避免静默覆盖、截断和错误转换。文件不合格就整批停止，保留原件并生成修正副本。复杂 InCites/JCR 导入不能假装适用此简单论文采集接口，应使用专用流程另行接通。

`publication-import` 没有 `--apply` 等同预检。明确导入后才提交；成功后逐条回读全部采集记录 ID 与题名。保存批次、数据版本、接受条数、自动核验资格和人工处理条数。**有自动核验资格不等于已核验；入库采集队列不等于已进入规范知识对象、HugeGraph 或正式分析。** 不自动调用确认/拒绝/发布接口，不同步检索外部文献网站。后续补全或发布另需明确任务。

## 防重复及恢复

当前后端论文批量导入没有跨客户端幂等键。脚本用固定状态目录中的“目标环境 + 实际身份 + 文件内容摘要”记录提交；文件重命名、改来源标签、重跑命令不会重复提交。同一文件从其他客户端导入、或内容不同但论文相同，仍需检查已有队列和论文匹配结果；不能宣称全系统去重已完成。

提交前落盘，提交后先保存服务端响应，再回读。断网/超时/服务端异常发生在响应之前时状态为结果未知，**不自动重投**；从中台“导入与清洗”及审计核实是否已产生批次，再恢复。响应已收到但回读失败时，重跑原命令只回读，不重新提交。检查状态回执，不删除保护文件或换环境/目录重试。

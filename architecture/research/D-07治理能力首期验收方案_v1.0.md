# D-07 治理能力首期验收方案 v1.0

- 状态：首期 synthetic 基线已执行通过；真实数据生产验收待后续执行
- 日期：2026-08-26
- 当前验收对象：SmartLib 最小治理域；OpenMetadata 在真实数据阶段另立 POC

## 1. 必须贯通的展示场景

1. 电子资源许可：展示资源、允许/禁止用途、内容粒度、用户范围、有效期和依据；
2. 数据质量：展示规则、最近运行、问题严重性、责任人、状态和处理记录；
3. 来源追溯：从学者/成果/资源/关系回到来源、外部 ID、版本、证据和处理时间；
4. 治理驾驶舱：从数据库按当前身份汇总来源、许可、质量问题和审计活动。

## 2. 绝对门槛

以下任一失败不得将治理模块标记为真实平台初版：

1. 前端数字与许可矩阵仍来自固定数组；
2. 无权用户通过汇总、列表、导出或错误信息获知受限资产存在性；
3. 到期/暂停许可仍允许受控用途；
4. 许可用途缺失时默认允许；
5. 质量问题无法关联资产、规则、运行和责任人；
6. 对象/关系不能追溯到来源和证据；
7. 修改或审核未生成 append-only 审计；
8. synthetic 数据没有真实性标记或被表述为真实学校数据；
9. Public API 暴露底层元数据产品实体或查询语言。

## 3. 数据与权限哨兵

- 有效公开许可、有效校内许可、已到期许可、已暂停许可；
- 允许摘要但禁止全文/TDM/向量化的许可；
- 公开资产引用私有证据；
- 公共质量汇总中包含另一个用户的私有资产问题；
- 相同规则在成功、警告、失败和未运行状态；
- source → reference → object → relation → evidence 完整链；
- `synthetic=true` 与未来 `real` 来源严格区分。

- 未授权资产、计数、许可和问题泄漏：0；
- 许可用途判定期望结果一致率：100%；
- 对象/关系来源追溯覆盖率：100%；
- 质量问题责任关联覆盖率：100%；
- 治理写操作审计覆盖率：100%；
- synthetic 标识展示覆盖率：100%；

## 6. OpenMetadata 后续 POC

获得真实技术元数据后另行验证：连接器覆盖、字段/管道血缘、数据契约、质量、SSO/RBAC、升级恢复、资源成本，以及与 SmartLib 许可/证据模型映射。POC 不得要求应用改用 OpenMetadata ID 或直接调用其 API。

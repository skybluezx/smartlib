### 准入门 2：安全连接

- 必须有独立测试凭据或受控样本；
- 凭据必须通过密钥引用注入，不能进入代码、配置仓库、运行清单或日志；
- 生产数据库直连和 CDC 必须有责任部门、数据库管理员和安全负责人批准；
- 出站地址、协议、证书和最小权限账号必须可列入白名单；
- 恶意文件、压缩炸弹、宏、路径穿越和超大对象必须有隔离策略。

### 准入门 3：可识别与可追溯

- 每个记录必须有稳定外部 ID，或形成经责任部门确认的复合幂等键；
- 必须区分事件发生时间、源修改时间和 SmartLib 接收时间；
- 必须明确更新与删除语义；
- 必须能把规范对象追溯到源数据集和外部 ID；
- 不允许仅凭姓名把人员记录直接认定为同一学者。

## 7. 样本交付要求

真实样本交付前确认：

- 使用专门测试账号或经过批准的受控导出；
- 样本覆盖正常、边界、重复、删除、缺失和异常记录；
- 样本附数据字典、数量、时间范围和校验和；
- 样本通过批准的加密交换渠道，不通过聊天或个人网盘；
- 文件名和内容不包含明文凭据；
- 样本保留期限和销毁责任明确；
- 测试、截图、日志和演示中是否需要脱敏已经确认。

## 9. 技术 POC 选择

根据真实源特征选择执行器，不预先把所有源都交给同一产品：

| 真实源特征 | 首选 POC |
|---|---|
| 特殊正式 API、OAI-PMH/SRU、许可语义复杂 | SmartLib Python 原生连接器 |
| 受控 CSV/JSON/XML/Excel 小中批量 | Python 原生连接器作为契约基线；SeaTunnel 同场比较 |
| 标准 JDBC 大批量快照 | SeaTunnel Zeta + Python 基线 |
| 已获正式 CDC 权限 | SeaTunnel Zeta CDC；必须保留平台检查点与 manifest |
| 多个 Airbyte 官方稳定 SaaS 连接器覆盖 | 触发 Airbyte 条件评估 |
| 边缘节点、持续文件路由、持久背压、既有校级 NiFi | 触发 NiFi 条件评估 |

# 论文导入与核验契约

> 当前版本 V39：所有读写直接使用通用导入表与论文、代表作扩展，旧导入视图和接口已移除。参见 [当前结构与接口](generic-ingestion-and-domain-provenance.md)。

## 支持的入口

- 单篇录入：页面表单提交结构化字段。
- 批量导入：UTF-8 CSV 或 XLSX，读取首个工作表，单文件不超过 20 MB、5,000 条。
- 批量文件先完成整批格式校验；任一数据行不符合接收标准时，整批不写入。

## 字段契约

| 字段 | 接收入库 | 自动核验资格 | 说明 |
| --- | --- | --- | --- |
| 论文题名 | 必填 | 必填 | 唯一的最低接收字段 |
| DOI | 可缺省 | 必填 | 当前自动核验以 DOI 精确查询 Crossref |
| 发表年份 | 可缺省 | 必填 | 用于年份一致性检查 |
| 期刊名称 | 可缺省 | 建议 | 两边均有值时参与一致性检查 |
| PMID、PMCID | 可缺省 | 可选 | 有值时与 NCBI PubMed 交叉核验 |
| 作者列表 | 可缺省 | 条件必填 | 声明成果归属人时必须提供，使用分号或换行分隔 |
| 成果归属人 | 可缺省 | 可选 | 表示需要核验学者与论文的作者关系 |
| 代表性论著编号 | 可缺省 | 可选 | 业务来源内部编号，不作为论文身份主键 |

题名存在但不满足自动核验资格的记录允许进入系统，状态直接标记为“待人工核验”，并保存具体缺项原因。

## 自动核验状态

“具备自动核验资格”只表示证据足以运行规则，不表示已经通过。当前规则要求：

1. DOI 精确命中 Crossref；
2. 题名相似度不低于 97%；
3. 来源年份与权威年份均存在，且相差不超过 1 年；
4. 来源和权威记录均有期刊名称时，相似度不低于 75%；
5. 有 PMID 时，PubMed 题名相似度不低于 95%，PubMed DOI 与 Crossref DOI 不冲突；
6. 身份、标识符、版本状态和适用的作者归属等阻断检查全部执行并通过。

摘要、主题词、基金详情等补充信息缺失不阻断论文身份通过。

## 当前有效状态

| 状态 | 含义 |
| --- | --- |
| 已标准化 | 满足自动核验资格，等待权威来源核验 |
| 待人工核验 | 导入信息不足以运行完整自动核验，或首次核验需要人工判断 |
| 自动确认 | 所有适用阻断项已经执行并通过 |
| 人工确认 | 人工处理阻断项后确认 |
| 修正后确认 | 人工选择或更正字段后确认 |
| 待重新核验 | 后续证据出现关键待确认项，或阻断检查尚未完成 |
| 核验冲突 | 后续证据与当前论文身份发生阻断性冲突 |
| 已驳回 | 人工确认来源记录不应写入 |

后续全文、标识符、基金或出版状态补充会重新计算当前有效状态。关键冲突会覆盖原来的“自动确认”显示；冲突处理完毕且阻断项再次全部通过后，系统恢复最近一次有效决定。

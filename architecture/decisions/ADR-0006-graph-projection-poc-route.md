# ADR-0006：图投影 POC 路线

- 状态：已被 ADR-0013 取代（保留为历史记录）
- 日期：2026-08-25
- 决策人：项目负责人
- 关联编号：D-05

## 背景

> 2026-09-01，项目负责人决定由 HugeGraph 1.7.0 彻底替换 Neo4j。当前有效决定见
> ADR-0013；下文仅记录此前 POC 的选择与验证历史。

SmartLib 已在 PostgreSQL 18 中保存规范对象、关系断言和关系证据。知识网络需要支持权限感知的邻域、有限多跳路径和证据解释，但真实规模、采购预算和生产 HA 要求尚未确认。图产品只能是可重建投影，上层入口不得直接查询产品 DSL。

## 决策

采用 Neo4j Community 固定版本作为专用图投影 POC 主路线，以 PostgreSQL 18 规范关系表和递归查询作为正确性、权限和低复杂度基线。

Apache AGE 1.8/PG18 在稳定制品、升级路径、RLS、备份和独立 PG18 图投影实例验证完成后加入副线；当前不把它安装到权威 PostgreSQL。NebulaGraph 只有真实规模和 SLA 证明其他候选不足时再评估。

本决策不等于选择 Neo4j 作为生产底座，也不授权采购 Neo4j Enterprise。

## 必须保持的边界

- PostgreSQL 是关系事实与证据的权威来源，图引擎只保存投影；
- 统一 `GraphPort` 暴露领域查询，不暴露 Cypher、SQL、nGQL 或驱动对象；
- 节点、边、中间路径、证据、计数和路径存在性全部执行权限与许可过滤；
- Web、API、MCP、Skill、Agent、小程序和客户端共享同一能力契约；
- Outbox 投影幂等、支持乱序保护、撤回、删除和全量重建；
- Community 数据库不面向终端用户或外部 Agent 开放，仅允许隔离投影账号访问。

## 验证与接受条件

以《D-05 图数据 POC 验收方案 v1.0》为准。至少完成多跳合作路径、学科—团队—资源证据链、成果—能力—需求匹配三类真实查询；权限泄漏必须为零；投影重建后对象、关系、证据、版本和策略一致率必须为 100%。

当前“已接受”只表示 POC 主路线和工程边界已经确认。只有在真实数据 POC 完成、生产所需 Edition/许可/HA/备份成本明确后，才能另行作出生产图产品决策；不得把本 ADR 解读为生产采用结论。

## 首轮实施记录（2026-08-26）

- 固定 `neo4j:2026.07.1-community`，本地取得镜像摘要 `sha256:dbc377fb9cd8fe8dabc19d3041b197d5ca0ef8bae514cea175b8df265e5b7a76`；
- 已建立隔离的 `graph-poc` Compose profile、约束/索引初始化、独立投影 worker 和可重建卷；
- 已实现 `GraphPort`、PostgreSQL 权威基线、Neo4j 适配器，以及邻域、有限路径、关系解释三个公共能力；
- 关系与证据写入先提交 PostgreSQL，并通过 Transactional Outbox 幂等投影到 Neo4j；公共 API 不接收 Cypher；
- 真实运行切片中，Neo4j 与 PostgreSQL 均返回 SmartLib 核心对象的三节点、两关系、两跳路径及证据/版本元数据；
- 权限哨兵验证通过：私有中间节点对非拥有者不产生残缺路径或存在性结果；公开关系引用私有证据时，非拥有者得到空证据列表，拥有者可见证据 ID；
- 本记录完成阶段 A 的工程骨架与安全机制验证，尚未完成三类授权真实业务场景、规模曲线、重建/恢复演练及生产许可成本评估。

## 退出方案

- 专用图收益不足：首版继续使用 PostgreSQL `relation_assertion` 基线；
- Neo4j 通过但 Enterprise 成本不可接受：评估 AGE 独立投影实例；
- AGE 稳定性/升级不达标：不在权威 PostgreSQL 安装扩展；
- 规模超出单实例能力：以同一 GraphPort 和验收集加入 NebulaGraph 或其他分布式图产品；
- 所有情况下均由 PostgreSQL 权威状态重建，不迁移权威责任。

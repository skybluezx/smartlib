# 合作结构分析：簇级成果组合与中心候选 v1

## 统计范围与来源

保留 cooperation-louvain-v1 的全范围分簇、全部现有结构指标。每簇使用至少有两位本簇成员署名的范围内论文，按论文 ID 去重；单人簇采用个人论文。跨簇论文可计入多个簇，各簇不得相加作为全局总量。下方探索/边数截取不改变成果组合或中心计算。

期刊数据复用 graph_analytics 同年匹配和统一准入规则。记录 record_id、release_id、metric_year。待核数据沿用当前准入，不修改核验状态。InCites 从授权分析视图选最新且与当前范围相交的一个完整版本，不跨版本补缺；validated 指来源批次通过结构验证，不代表逐篇人工核验。

## 聚合定义

同年 JCR JIF 与导入 InCites 九项数值各自展示：有值论文数、缺失/冲突论文、算术平均、中位数、最小与最大值。零值有效，缺失不补零，多条相同值去重，多条冲突值不参与聚合。被引频次增加总量；CNCI、JNCI、Collab-CNCI 增加严格大于 1 的篇数和有效样本内占比。规范化指标逐篇平均，不取实际/预期总量之比。

JCR Q1—Q4 与独立中科院分区各自统计；每篇按类别等权分摊，分母为该体系有效论文数。每个 record_id 只计一次。不同系统不合并；缺少同年分区保持缺失。JIF 不求总分，InCites JIF 不补填 JCR。三个预期指标只作样本基准背景，不作为绩效。

## 中心候选

簇内完整诱导子图中，计算加权度（共同论文数之和）和精确无权归一化介数中心性。介数使用 NetworkX Brandes 实现，最短路径为合作步数，未将合作权重误作距离。按确定的节点/边顺序计算，介数保留 12 位小数避免浮点尾差。

各指标分别取前 ceil(人数×10%) 名对应分数阈值，包含所有并列且分数大于 0 的成员，合并候选。若一项指标全部同值则不按该指标指定中心。孤立人员无中心。首屏最多预览三名，明细列出全部候选及加权度、合作者数、介数；并非仅有三名中心。

10% 是可审查的探索性选择参数，不是学术共识阈值，不认定团队负责人或正式多中心团队。大规模合著也可能提高加权度。保留全部论文和成员依据，需结合真实贡献和专家判断。

方法来源：https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.centrality.betweenness_centrality.html

## 可复现与验收

metric_context、metric_inputs 冻结版本、截止日期及逐论文指标来源；metric_input_hash 结合结构指纹与完整指标输入独立计算。导出包含结构和指标依据；replay_cooperation_assessment.py 同时复算，避免指标更新伪装成同一次分析。

当前数据缺少学校完整成果和历年记录，不将上述指标合成为科研质量总分或因果结论。

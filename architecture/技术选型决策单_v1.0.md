## 决策前需持续收集的组织事实

- [ ] 现有开发团队 Java、Python、TypeScript/Vue 人力与经验
- [ ] 学校统一身份支持的协议及测试环境
- [ ] 学校容器、Kubernetes、数据库、消息、对象存储和日志平台现状
- [ ] 首批 1–2 个业务系统正式接口和责任人
- [ ] 首批电子资源合同许可矩阵
- [ ] 首批数据量、日增量和期望更新时间
- [ ] 国产化、等保、密码应用与数据出域要求
- [ ] 图数据库或商业支持的采购预算边界
- [ ] 小程序、原生/桌面客户端的目标用户、设备和发布时间
- [ ] 外部 AI 客户端、MCP 和 Agent 的网络开放与数据出域边界
- [ ] 校内受管终端的 Chrome/Edge/Firefox/Safari 最低版本与不可升级设备范围
